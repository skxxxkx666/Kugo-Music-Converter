## Kugo Music Converter v0.6.0

> 状态：四资产发布链、全部真实样本回归及 Windows 10/11 最终验收完成。当前稳定版本为 v0.6.0。

v0.6.0 是一次桌面化重大升级：项目从“HTA / BAT 启动本地 HTTP 服务并跳转浏览器”
迁移为 Wails v2 单 EXE Windows 桌面应用。解密和转码继续在本机执行，用户文件不会发送到网络。

### 桌面化与启动流程

- 提供统一的 `Kugo Music Converter.exe` 桌面入口；
- 不再依赖 `start.hta`、`start.bat`、系统浏览器或 `localhost` 服务；
- 桌面进程不监听 TCP 端口，前后端通过 Wails 绑定和事件通信；
- 支持 Windows 10 / 11 64 位，不适配 Windows 7；
- 标准版使用系统 WebView2 Runtime；另提供内置 Fixed Runtime 的大体积单 EXE。

### 单 EXE 运行时

- 正式构建强制使用 `runtimebundle,release`，将 FFmpeg 嵌入 EXE；
- 首次需要时解压到应用管理的本地缓存目录；
- 对内嵌运行时进行完整性校验，并复用已验证缓存；
- 用户无需单独下载或配置 FFmpeg。

### 文件、文件夹与队列

- 支持选择文件、拖放文件和选择文件夹；
- 支持文件夹递归扫描和批量导入；
- 队列最多容纳 500 个项目；
- 支持删除单项、清空队列和查看逐项状态；
- 队列行显示彩色扩展名徽章，支持单击选中、双击试听和右键上下文菜单（试听 / 定位 / 重试 / 复制文件名 / 复制路径 / 移除）；
- 键盘快捷键：Ctrl+O 选择文件、Enter 开始转换、Esc 取消转换、Delete 移除选中项；
- 对不支持的格式、重复项和超出上限的项目给出明确反馈。

### 格式与转换设置

- 继续支持 KGG / KGM / KGMA / VPR / NCM 解密；
- 新增酷我 KWM；
- 新增传统 QMC0 / QMC2 / QMC3 / QMC4 / QMC6 / QMC8 / QMCFLAC / QMCOGG / TKM；
- 新版 MFLAC / MGG 因依赖设备密钥或 MMKV，本版本不宣称支持；
- 支持 MP3 / FLAC / WAV 输出，或保持解密后的原始音频格式；
- 支持输出目录、输出格式、MP3 音质和并发数等设置；

## Kugo Music Converter v0.5.0

Kugo Music Converter 是一款酷狗音乐加密文件解密转换工具，支持 KGG / KGM / KGMA / VPR / NCM 等格式的解密与转码

### 使用方法

1. 下载并解压发布包
2. 双击 `start.hta` 启动（备选：`start.bat`）
3. 浏览器自动打开操作界面，拖入文件或选择文件夹即可开始转换

### 系统要求

- Windows 10 / 11 (64-bit)
- 无需安装任何运行时环境

### 更新内容

**解密内核重写（核心）**
- 修复 QMC2 MAP 位运算错误：还原酷狗既定的 `(v<<r)|(v>>r)` 非循环移位，此前会导致几乎所有 MAP 模式 KGG 解出乱码
- 按标准重写 QMC2 RC4：分段密钥 `skip` 由 `& 0x1FF` 改为 `% len(key)`，并改为每段以 KSA box 副本重跑 PRGA，修复仅当密钥恰为 512 字节才正确的缺陷
- ekey V1/V2 与 TEA-CBC 按标准忠实重写，补全 V2（`EncV2`）路径的 base64 解码
- MAP / RC4 模式阈值与标准统一为 `len(key) > 300` 走 RC4

**数据库与稳定性**
- `KGMusicV3.db` 改为全程内存解密，不再向系统临时目录写出明文密钥库
- 首页解密后新增完整性校验，master key 失配时给出明确错误而非模糊报错
- master key 支持环境变量 `KGG_DB_MASTER_KEY`（hex）覆盖，预留降级空间
- 解库结果按 路径 + 大小 + 修改时间 进程级缓存：批量转换只解库一次，重载新 `KGMusicV3.db` 后自动失效

**解析健壮性**
- KGG 头部改为结构化解析并校验 16 字节 magic，格式异常时报错清晰

**前端与提示**
- 修正本地转换误报“请检查网络连接”的问题
- SSE 中断细分为 `ERR_BACKEND_UNREACHABLE`（本地服务未连接）与 `ERR_STREAM_NO_COMPLETE`（中途断流），保留 `ERR_STREAM_DISCONNECTED` 兼容
- 转换前新增本地服务健康检查，未启动后端时直接拦截并给出启动指引

**测试与质量**
- 解密单元测试改为独立参考实现 + 已知答案向量 + 真实文件回归，消除此前“参考实现复用被测代码”的循环论证
- 8 个真实样本（含 6 个 RC4 模式）整文件与标准实现逐字节一致

**版本与维护**
- 版本号升级为 `v0.5.0`
- 新增直接依赖 `golang.org/x/crypto/tea`
- `tailwind.config.js` 插件改为可选加载，无 Node 依赖环境重编译不再失败

* 前端完全重写为模块化架构（12+ ES 模块）
* 音频试听功能（转换完成后可直接播放）
* 历史记录管理（恢复/删除/导出）
* 虚拟列表支持大批量文件预览
* 拖拽上传支持目录递归解析
* 转换完成桌面通知 + 提示音
* 配置面板自动折叠

**重构与改进**

* 后端 handler 层拆分为 6 个文件，职责更清晰
* 批量转换引擎重写，支持字节级进度与 ETA 预估
* 路径解析增强（多级候选、跨目录查找）
* 配置支持 YAML + 环境变量 + CLI 三级覆盖

**安全加固**

* 修复 SSE 连接竞争条件与文件输出路径竞争
* 新增 JSON 请求体大小限制、目录扫描超时防护
* XSS 转义增强、关闭期间阻止新任务

**Bug 修复**

* 修复 SSE 流读取空值崩溃
* 修复拖拽事件不对称导致的 UI 残留
* 修复文件夹打开/选择器的错误处理
